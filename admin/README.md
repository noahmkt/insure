# 내보험 찾기 — 운영 관리자 웹 (`admin/`)

실손보험 청구 간소화 서비스의 운영 관리자 웹 데모. 근거 문서:

- `docs/02-wireframes.md` §7 (관리자 웹 핵심 화면)
- `docs/04-api-spec.md` §9 (관리자 API, RBAC)
- `docs/05-matching-rules-v1.md` (세대별 공제 파라미터)

## 실행

```bash
cd admin
npm install
npm run dev      # http://localhost:5174 (백엔드 :3000 으로 /api 프록시)
npm run build    # 타입체크(tsc) + 프로덕션 빌드
```

백엔드(`backend/`, `npm run start:dev`)가 없어도 동작한다 — API 호출 실패 시 각 화면이
**목데이터 폴백**으로 전환되며, 화면 우측 상단 배지로 `서버 데이터` / `목데이터 폴백`을 표시한다.

## 기술 스택

Vite + React + TypeScript. 의존성 최소화 — 라우터·상태 라이브러리 없이 `useState` 탭 전환.

## 화면

| 탭 | 내용 | 접근 롤 |
|---|---|---|
| 대시보드 | 신규가입 · 연동성공률 · 발굴건수/예상금액 · 숨은보험금(확정) · 상담신청 · 청구전환율 · 예측오차 | 전체 |
| 상담 큐 | 신청 목록, 상태 필터, 담당자 배정(배정 시 **③ 제3자 제공 동의 증적 자동 첨부** 표시) | 운영자·상담사 (배정은 운영자만) |
| 서류 검토 | 뷰어 전용(다운로드 버튼 없음), 검수 체크리스트, 보완 요청(고객 앱 푸시), 손해사정사 플래그 | 상담사·손해사정사 (플래그 토글은 손해사정사만) |
| 필요서류 매트릭스 | 보험사 × 청구유형(통원/입원/약제) × 금액구간 테이블 편집 | 운영자 |
| 매칭 파라미터 | 실손 1~4세대 공제 파라미터 편집 + 룰 버전 이력(저장 시 새 버전 발행) | 운영자 |
| 감사 로그 | 민감정보 열람 전건 (누가·언제·어떤 고객·어떤 데이터), append-only | 감사·운영자 |

## RBAC 데모

상단 바에서 역할(운영자/상담사/손해사정사/감사)을 전환하면 메뉴 노출과 액션 버튼이 바뀐다.
**감사(AUDITOR)는 read-only** — 어떤 변경 액션도 노출되지 않는다.
데모에서는 `x-staff-id` / `x-staff-role` 헤더로 역할을 전달하며(백엔드 데모 RBAC 규약),
운영 환경에서는 SSO + 서버측 RBAC 가드로 대체된다. 서버가 항상 최종 권한을 강제한다.

## API 클라이언트

`src/api.ts` — `/api/v1/admin/*` 호출(2.5초 타임아웃). 실패(백엔드 미기동, 미구현 엔드포인트,
권한 오류) 시 `src/mock.ts` 의 목데이터로 폴백한다. 백엔드에 실제 구현된 엔드포인트:
`POST /admin/consultations/:id/assign`, `GET /admin/audit-logs`, `GET /admin/accuracy`,
`GET /admin/users/:userId/medical`. 나머지는 목데이터로 동작한다.

## 법적 하드 룰 반영 사항

1. **청구 대행·성공보수 금지** — "제출" 실행 기능·문구 없음. 서류 검토 완료는 내부 검수 상태일
   뿐이며, 화면·푸터에 "최종 제출은 고객 본인이 직접 수행" 고지.
2. **주민등록번호 원문 저장 금지** — CI 기반. 코드·목데이터·화면 어디에도 주민번호 필드/패턴
   없음. 고객 표기는 전부 마스킹(`김○○`, `u-9021`).
3. **민감정보 접근통제** — 서류 검토(민감정보) 화면 상단에 "모든 열람 기록이 감사 로그에
   남습니다" 고지. 뷰어 전용(다운로드 버튼 없음). 열람 권한은 서버에서 "상담 신청 고객 건 +
   배정 담당자"로 강제.
4. **동의 4층 분리** — ③ 제3자 제공 동의는 상담 신청 클릭 시점에 수집된 증적을 사용하며,
   담당자 배정(리드 전달) 시 자동 첨부되어 감사 로그에 기록됨을 UI 에 표시.
5. **목적 외 이용 금지** — 민감정보 화면·푸터에 고지.
6. **"전문가 상담 신청" 프레임** — 상담 큐에 "고객이 직접 신청한 전문가 상담 건, 상품 권유
   목적 연락 금지" 고지.
7. **예측 금액 표기 규칙** — 예측 금액은 항상 `예상` 접두 + 산출 근거(펼침) + 면책 문구
   "실제 지급액은 보험사 심사에 따라 달라질 수 있습니다." 확정액(숨은보험금)은 별도 카드에
   "확정" 라벨로 분리 집계(혼용 표기 금지).
