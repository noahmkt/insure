# Phase 1 (MVP) 스프린트 백로그 — 2주 단위 8스프린트 (약 4개월)

전제: Phase 0 완료(CODEF 샌드박스 PoC 성공, 법무 자문 1차, 상위 5사 서류 매트릭스 초안, 와이어프레임 확정).
팀 가정: 백엔드 2, 앱(Flutter) 2, 프론트(관리자) 1, 디자인 1, PM 1. DoD(공통): 코드리뷰 + 테스트 + 하드 룰 체크리스트 통과.

## Sprint 1 — 기반

- [ ] 모노레포/CI 파이프라인(빌드·테스트·린트), 개발/스테이징 환경(국내 리전)
- [ ] DB 스키마 v1 마이그레이션(core/medical 스키마 분리, 롤 분리)
- [ ] KMS 연동 필드 암호화 유틸(AES-256-GCM) + 로그 주민번호 마스킹 필터
- [ ] 본인인증(PASS/카카오) 연동 → CI 수신 → 계정 생성 API
- [ ] 앱: 프로젝트 셋업(Flutter+Riverpod), 디자인 시스템 토큰, 스플래시/소개 3장

## Sprint 2 — 동의 + 연동 골격

- [ ] 동의 4층 API(부여/철회/이력, append-only) + 철회 영향 안내
- [ ] 어댑터 인터페이스(`MedicalDataProvider`/`InsuranceContractProvider`) + CODEF 구현체(간편인증 비동기 잡, 폴링/웹훅)
- [ ] sync_jobs 상태머신 + 실패 재시도 큐 + 소스 헬스체크
- [ ] 앱: 회원가입 플로우(본인인증), 동의 화면(①②)

## Sprint 3 — 데이터 수신 + 내 보험

- [ ] 보험계약 수신·정규화 + 실손 세대 자동 태깅 + 중복 실손 감지
- [ ] 진료내역 수신·정규화(medical 스키마, 암호화 저장) + 캐싱 정책(주1회/월1회)
- [ ] 앱: 연동 마법사(스켈레톤 UI, 예상 소요, 재시도/건너뛰기), 내 보험 탭(리스트/상세)

## Sprint 4 — 매칭 엔진 + 환급금 탭

- [ ] 담보 매칭 엔진 v1(세대별 파라미터 테이블 외부화, 산출 근거 문자열, UNDETERMINED 라벨)
- [ ] 숨은보험금(확정액) 수신·표기 분리 + 환급금 API(정렬: 예상액/소멸시효)
- [ ] 면책 문구 직렬화 강제(예측 DTO) + 금액 표기 정책 공통 컴포넌트
- [ ] 앱: 홈(히어로 카드, 구분 뱃지), 환급금 탭(토글, 산출 근거 펼침, D-day)

## Sprint 5 — 간편청구 B플로우 1/2

- [ ] 필요서류 매트릭스 CRUD + 상위 5사 데이터 시딩
- [ ] 청구건 생성(다중 진료건) + 라우팅 판별(A/B) + A플로우 실손24 딥링크 가이드
- [ ] 체크리스트 자동 생성 API
- [ ] 앱: 병원/진료건 선택, 라우팅 분기 화면

## Sprint 6 — 간편청구 B플로우 2/2

- [ ] 서류 업로드(오브젝트 스토리지 SSE-KMS) + OCR(영수증 금액·항목) 연동
- [ ] 제출 준비 완료 패키지(접수 채널 안내 + 청구서 양식 생성) — 제출 API 미구현 원칙 유지
- [ ] 전자서명(위임장·동의서) — 법무 자문 결과 반영
- [ ] 청구 상태 타임라인 + 실지급액 입력(정확도 축적)
- [ ] 앱: 서류 촬영/업로드, 패키지 화면, 상태 관리 화면

## Sprint 7 — 관리자 + 상담(리드)

- [ ] 관리자 웹: 로그인/RBAC 4롤, 대시보드 v1
- [ ] 상담 신청 API(③동의 클릭 시점 수집 + 증적 연결) + 상담 큐/배정 + 리드 전달 증적 자동 첨부
- [ ] 서류 검토 워크플로(뷰어 전용, 보완 요청 푸시, 손해사정사 플래그)
- [ ] 감사 로그(민감정보 열람 전건) + AUDITOR 화면
- [ ] 앱: 내 보험 탭 상담 CTA + ③동의 모달, 마이 탭(동의 관리, 보관함, 상담 내역)

## Sprint 8 — 알림 + 하드닝 + 베타

- [ ] 알림 파이프라인(푸시/알림톡): 신규 발굴, D-90/D-30, 보완 요청, 검토 완료, 상담 배정
- [ ] 회원 탈퇴 즉시 파기 + 법정 보존 분리 + 파기 배치(진료내역·보관함)
- [ ] 보안 점검: 주민번호 잔존 스캔 배치, 침투 테스트, 성능(홈 2초)
- [ ] 예측 정확도 대시보드 v1
- [ ] 클로즈드 베타 100명 온보딩 + 지표 계측(활성화/Aha/전환 퍼널)

## 상시 트랙 (스프린트 외)

- 법무: 동의서 4종 검수, 전자서명 효력, 모집행위 규제 검토(GA 구조)
- 데이터: 필요서류 매트릭스 확장(5사 → 10사), 매칭 파라미터 손해사정사 검수
- 리스크: 하드 룰 체크리스트를 PR 템플릿에 포함(성공보수·대행·주민번호 저장·혼용 표기 금지)
