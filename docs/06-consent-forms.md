# 동의서 4종 문구 초안 (법무 검수 전제)

> 모든 문구는 **법무 검수 완료 전 사용 금지**. 각 동의는 독립 철회 가능해야 하며,
> 철회 시 기능 영향 범위를 즉시 안내한다. 동의 이력은 버전·일시·수단(체크/서명)과 함께
> 불변 로그(`core.consents`)로 보관한다. 포괄 동의 금지.

## ① 개인정보 수집·이용 동의 (필수 / 회원가입 시)

문서 버전: `consent-personal-v1`

```
[필수] 개인정보 수집·이용 동의

1. 수집 항목
   - 본인인증 결과값(CI), 이름, 휴대전화번호
   - 서비스 이용기록(접속 일시, 이용 내역)
2. 수집·이용 목적
   - 회원 식별 및 계정 관리, 서비스 제공(보험금 발굴·청구 안내), 고객 문의 대응
3. 보유·이용 기간
   - 회원 탈퇴 시 즉시 파기. 단, 관계 법령에 따라 보존이 필요한 정보는
     해당 법령이 정한 기간 동안 분리 보관 후 파기합니다.
4. 동의 거부 권리 및 불이익
   - 동의를 거부할 수 있으나, 거부 시 회원가입 및 서비스 이용이 불가합니다.

※ 주민등록번호는 수집하지 않습니다.
```

## ② 민감정보(건강·진료정보) 처리 동의 (필수 — 데이터 연동 기능 한정 / 연동 직전)

문서 버전: `consent-sensitive-v1` · 근거: 개인정보보호법 제23조

```
[필수*] 민감정보(건강·진료정보) 처리 동의
*데이터 연동 기능 이용 시에만 필요합니다.

1. 처리 항목
   - 국민건강보험공단 진료 및 투약 내역(진료일, 요양기관, 본인부담금, 처방 내역)
   - 보험계약의 보장 내용(담보) 정보
2. 처리 목적
   - 미청구 보험금 발굴을 위한 진료내역-보험 담보 매칭 분석
   - 청구 필요서류 안내 및 청구 진행 상태 관리
3. 보유·이용 기간
   - 목적 달성(청구 완료 또는 회원의 삭제 요청) 시 지체 없이 파기합니다.
4. 처리 방법
   - 암호화 저장 및 역할 기반 접근통제를 적용하며,
     본 동의 목적(청구 지원) 외 보험 상품 권유 등 영업 목적에 사용하지 않습니다.
5. 동의 거부 권리 및 불이익
   - 동의를 거부할 수 있으며, 이 경우 데이터 연동 기능만 제한되고
     그 외 서비스는 계속 이용할 수 있습니다.
```

## ③ 개인정보 제3자 제공 동의 (선택 / **상담 신청 버튼 클릭 시점**)

문서 버전: `consent-thirdparty-v1`

```
[선택] 개인정보 제3자 제공 동의 (전문가 상담 연결)

1. 제공받는 자
   - 회사와 제휴한 법인보험대리점(GA) 소속 배정 설계사 또는 손해사정법인 소속 손해사정사
     (배정 확정 시 앱 내 '상담 내역'에서 소속·성명을 확인할 수 있습니다)
2. 제공 항목
   - 이름, 휴대전화번호, 보험 가입 요약(보험사·상품명·실손 세대)
   ※ 진료내역 등 민감정보는 별도의 명시적 동의 없이 제공되지 않습니다.
3. 제공 목적
   - 회원이 신청한 보험 점검 상담 또는 전문가 검토 상담의 수행
4. 보유·이용 기간
   - 상담 종료 후 3개월 이내 파기
5. 동의 거부 권리 및 불이익
   - 동의를 거부할 수 있으며, 이 경우 전문가 상담 신청만 제한됩니다.
```

- 수집 시점 규칙: 이 동의는 가입 시점에 미리 받지 않는다. **상담 신청 버튼 클릭 시** 모달로 노출하고, 동의 레코드에 신청 건 식별자(`context`)를 연결해 증적을 남긴다. 리드 전달 시 이 증적이 자동 첨부된다.

## ④ 마케팅 정보 수신 동의 (선택 / 가입 시 또는 마이 탭)

문서 버전: `consent-marketing-v1`

```
[선택] 마케팅 정보 수신 동의

1. 항목: 이름, 휴대전화번호, 앱 푸시 토큰
2. 목적: 이벤트·혜택·신규 기능 안내 (앱 푸시, 문자, 알림톡)
3. 보유·이용 기간: 동의 철회 또는 회원 탈퇴 시까지
4. 동의를 거부해도 서비스 이용에 제한이 없으며,
   서비스 운영상 필수 알림(청구 상태, 서류 보완, 소멸시효 임박 안내)은
   본 동의와 무관하게 발송됩니다.
```

| ② 민감정보 | "진료내역 연동과 미청구 발굴 기능이 중단되고, 저장된 진료내역은 파기됩니다. 진행 중인 청구 안내는 보관함 서류 기준으로만 계속됩니다." |
| ③ 제3자 제공 | "진행 중인 상담이 종료되며, 전달된 정보는 파기 요청됩니다." |
| ④ 마케팅 | "이벤트·혜택 알림이 중단됩니다. 청구 상태 등 서비스 알림은 계속 발송됩니다." |
